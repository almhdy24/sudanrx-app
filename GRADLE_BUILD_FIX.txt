FLUTTER GRADLE BUILD FIX - SudanRx Project
============================================

Issue: Build failed with error - Plugin [id: 'dev.flutter.flutter-gradle-plugin', version: '1.0.0'] was not found
Job URL: https://github.com/almhdy24/sudanrx/actions/runs/26722511035/job/78752039805
Commit: f619a86f85c761f7bbedb25e1fac50bde500fdf3

ROOT CAUSE:
-----------
The android/settings.gradle.kts was explicitly declaring the Flutter plugin with a version that doesn't exist or is incompatible.
Flutter plugin versions should be managed by the Flutter SDK itself, not manually declared in build files.

SOLUTION:
---------
Update these three files:

1. android/settings.gradle.kts
   - Remove the explicit plugin declaration from pluginManagement
   - Keep only the repository definitions

2. android/app/build.gradle.kts  
   - Keep the plugin id("dev.flutter.flutter-gradle-plugin") declaration
   - DO NOT specify a version on it
   - Flutter will inject the correct version at build time

3. android/gradle.properties
   - Add org.gradle.diagnostics=false (optional but recommended)

HOW IT WORKS:
=============
- flutter precache --android (in CI/CD) downloads and prepares the correct Flutter plugin
- flutter build apk injects the correct plugin version automatically
- Manual version declarations in settings.gradle.kts conflict with this automatic injection
- Removing the version declaration allows Flutter tooling to manage it properly
